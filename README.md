# Гриф

Журнал тренировок для iPhone по программе 4.0 (верх / низ, 4 тренировки в неделю, 12 недель). Работает без интернета.

## Установка на iPhone
1. С интернетом откройте в Safari: https://andrejs-g.github.io/grif/
2. «Поделиться» → «На экран „Домой“».
3. Один раз откройте приложение с иконки. Дальше оно работает офлайн.

Записи хранятся на телефоне. Раз в неделю приложение отправляет их в приватный репозиторий (по умолчанию `Andrejs-G/grif-log`: `log/grif-log.json`, `log/sets.csv`) и забирает рекомендации из `plan/adjustments.json`. Резервная копия: вкладка «Программа» → «Сохранить копию».

## Сборка
`python3 src/build.py` собирает `index.html`, `sw.js`, `manifest.webmanifest` и иконки из `src/app.html`.
